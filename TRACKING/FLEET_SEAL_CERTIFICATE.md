# 🛡️ FLEET SEAL CERTIFICATE — EXODUS V2

> Ce fichier est un template. Le certificat réel est généré automatiquement
> par `EXO_FLEET_VALIDATOR.py --seal` après une validation E2E réussie.

## STATUT : ⏳ EN ATTENTE DE VALIDATION

Le certificat sera généré lorsque :
1. Toutes les frégates (U00–U06) passent la validation 3 couches
2. Tous les Phantom Links sont valides
3. Toutes les routes de transfert sont satisfaites

### Comment lancer la validation

```bash
# Via CLI
python EXO_FLEET_VALIDATOR.py --drive-root /path/to/DRIVE_EXODUS_V2 --mode full --seal -v

# Via Notebook
# Ouvrir EXO_FLEET_VALIDATOR.ipynb dans Colab et exécuter les 4 cellules
```
