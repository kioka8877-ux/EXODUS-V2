# EXODUS V2 — THE MARSHAL (L'Intendant)

**Ghost script de validation logistique inter-frégates.**
Le Marshal ne déplace, ne copie, ne supprime JAMAIS de fichier. Il lit et valide uniquement.

> *Loi III — Étanchéité : Aucune frégate ne peut accéder aux données internes d'une autre. Le Marshal vérifie les sas d'entrée et de sortie.*

---

## Installation

**Aucune dépendance.** Python 3.7+ standard library uniquement.

Modules utilisés : `os`, `sys`, `json`, `hashlib`, `datetime`, `argparse`, `pathlib`, `fnmatch`.

---

## Utilisation

### Check-Out — Vérifier les fichiers OUT/ avant transfert

```bash
python EXO_MARSHAL.py --unit U00 --mode check-out
```

Valide que tous les fichiers attendus dans les dossiers `OUT_*` d'une frégate sont présents, non vides, et conformes (JSON valide si applicable). Affiche ensuite les instructions de transfert vers les frégates destinataires.

### Check-In — Valider les fichiers IN/ après transfert

```bash
python EXO_MARSHAL.py --unit U01 --mode check-in
```

Valide que tous les fichiers attendus dans les dossiers `IN_*` d'une frégate ont bien été reçus. Si tout est conforme : **FRÉGATE PRÊTE AU LANCEMENT**. Sinon : **BLOQUÉE**.

### Validate — Check-Out + Check-In combinés

```bash
python EXO_MARSHAL.py --unit U04 --mode validate
```

Exécute les deux vérifications en séquence pour un diagnostic complet.

### Options supplémentaires

```bash
# Spécifier un répertoire racine custom (par défaut : auto-détection)
python EXO_MARSHAL.py --unit U00 --mode check-out --drive-root /content/drive/MyDrive/DRIVE_EXODUS_V2

# Mode verbeux — affiche tailles, hash SHA256 tronqués
python EXO_MARSHAL.py --unit U00 --mode check-out --verbose
```

### Identifiants d'unité acceptés

Le script accepte les formats `U00`–`U06` et `F00`–`F06` (insensible à la casse).

## Codes de sortie

| Code | Signification |
|------|--------------|
| `0` | Toutes les vérifications passées ✅ |
| `1` | Fichiers manquants ou corrompus ❌ |
| `2` | Arguments invalides / erreur de configuration |
